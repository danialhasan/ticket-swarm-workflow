# 20 Design And Implementation Contracts

Use these skills after product truth is clear enough to turn into contracts.

Skills:

- `design-contract-conveyor`: converts live design/product review into durable
  design contract rows.
- `implementation-contract-conveyor`: compiles approved readiness rows into
  seam-locked implementation contracts.
- `ticket-to-human-review`: gets human signoff on an implementation contract
  before development/testing begins.

Do not use this group to invent requirements that should have been discovered
by the product-truth layer.
