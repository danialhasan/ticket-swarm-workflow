# 40 Execution Orchestration

Use these skills only after the seam is locked and execution is ready to split.

Skills:

- `parallel-lane-orchestrator`: plans multiple dependency-ready tickets or
  lanes with explicit ownership and serialized-resource rules.
- `worktree-lane-orchestrator`: creates isolated git worktree/branch lanes for
  mutating parallel work on one ticket.

This group should not be the first stop for ambiguous product work.
