# 50 Review Reconciliation And Human QA

Use these skills after implementation and automated verification have produced
work that can be reviewed, collapsed, or signed off.

Skills:

- `worktree-lane-reconcile`: collapses parallel lane work back onto one
  surviving integration branch/worktree.
- `review-batch-orchestrator`: coordinates shared human-review waves with patch
  and re-review loops.
- `sequential-ticket-review-queue`: reviews implemented tickets one by one,
  merges surviving work, reruns mainline proof, and advances safely.
- `ticket-human-review-runtime`: prepares the right runtime surface and
  checklist for human product QA.
