# Release Receipt Checklist

Use this checklist when assembling the release handoff and outcome receipts.

## Deploy-readiness packet

- merged commit
- version or tag
- CI status
- verification status
- required test status
- human review status
- artifact status
- updater feed status
- human-trigger eligibility

## Artifact verification note

- artifact names
- manifest names
- compatibility manifest names
- publication status
- checksum or signature references
- release notes reference

## Updater verification note

- feed URL
- manifest URL
- package URL
- cache-bust check result
- current version observed

## Release decision receipt

- triggered by
- triggered at
- version released
- updater endpoint verified
- release notes reference
- rollback or re-release posture

## Blocked-release receipt

- blocking condition
- missing prerequisite
- recommended next action
